## 📝 Core Workflows

### 1. Script Ingestion and Breakdown

#### Step 1: Upload Script
1. Navigate to **Projects** → **[Your Project]** → **Script & Breakdown**
2. Click **"Upload Script"** button
3. Select your screenplay file (PDF or .fdx format)
4. Add any special notes or requirements
5. Click **"Upload and Process"**

#### Step 2: AI Processing
- PlotOps automatically extracts scenes, characters, and props
- AI analysis suggests complexity ratings and budget estimates
- Processing typically takes 2-5 minutes depending on script length

#### Step 3: Review and Edit Breakdown
1. Review the generated **Breakdown Table**
2. Edit scene information as needed:
   - Scene numbers and names
   - Location details
   - Time of day settings
   - Complexity ratings (1-5 scale)
   - Estimated page counts
3. Add or remove characters, props, and special requirements
4. Assign preliminary budget tags

#### Step 4: Approve Breakdown
1. Review all extracted information for accuracy
2. Make final adjustments
3. Click **"Approve Breakdown"** to finalize
4. Share with relevant team members

**Tips for Success**:
- Ensure script formatting follows industry standards
- Review AI suggestions carefully - they're starting points, not final decisions
- Use complexity ratings consistently across your project
- Add detailed notes for special requirements or considerations

### 2. Casting Management

#### Creating Casting Calls

1. **Navigate to Casting**
   - Go to **Casting** → **Casting Calls**
   - Click **"Create New Casting Call"**

2. **Set Up Casting Call**
   ```
   Title: Lead Role - Sarah Johnson
   Character: Sarah Johnson (from breakdown)
   Description: Strong-willed detective in her 30s
   Requirements: 
   - Age range: 28-35
   - Strong dramatic acting experience
   - Comfortable with action sequences
   Audition Sides: [Upload script excerpts]
   Submission Deadline: [Date]
   ```

3. **Configure Settings**
   - Set as public (visible on casting board) or private
   - Define submission requirements
   - Set audition date ranges
   - Add any special instructions

#### Managing Submissions

1. **Review Submissions**
   - View actor profiles, headshots, and reels
   - Rate submissions (1-10 scale)
   - Add private notes for each actor
   - Flag favorites for easy reference

2. **Create Shortlists**
   - Select top candidates for auditions
   - Organize by callback rounds
   - Schedule audition appointments
   - Send audition confirmations

3. **Conduct Auditions**
   - Use mobile app for on-location auditions
   - Record audition videos (with permission)
   - Take detailed notes during auditions
   - Rate performance immediately

4. **Make Casting Decisions**
   - Review all audition materials
   - Discuss with producers and directors
   - Select final cast members
   - Send notifications to selected and rejected actors

#### Public Casting Board

**For Actors** (Public Access):
- Browse open casting calls
- Submit applications with headshots and reels
- Track submission status
- Receive audition notifications

**For Casting Directors**:
- Manage public visibility of casting calls
- Review and organize public submissions
- Communicate with actors through the platform
- Track casting call performance metrics

### 4. Production Scheduling (The Stripboard)

#### Understanding the Stripboard

The stripboard is a visual timeline showing scenes in shooting order, optimized for efficiency and cost-effectiveness.

**Key Concepts**:
- **Scene Strips**: Visual blocks representing individual scenes
- **Clustering**: Grouping scenes by location, cast, or other factors
- **Day Breaks**: Divisions showing daily shooting schedules
- **Color Coding**: Visual indicators for scene types, locations, or complexity

#### Creating the Schedule

1. **Initial Setup**
   - Ensure all scenes are properly broken down
   - Verify cast availability dates
   - Confirm location availability
   - Set overall production dates

2. **Automatic Clustering**
   - PlotOps suggests scene groupings based on:
     - Location proximity and availability
     - Cast member schedules
     - Equipment and crew requirements
     - Weather considerations for exterior scenes
   - Review and adjust AI suggestions

3. **Manual Adjustments**
   - Drag and drop scenes to reorder
   - Create day breaks at logical points
   - Balance daily workloads (typically 4-8 scenes per day)
   - Consider cast and crew fatigue factors

4. **Schedule Validation**
   - Check for scheduling conflicts
   - Verify location availability
   - Confirm cast availability for all assigned scenes
   - Review budget implications of schedule changes

#### Call Sheet Generation

1. **Automated Generation**
   - Select shooting day from stripboard
   - Click **"Generate Call Sheet"**
   - System automatically includes:
     - Scene information and locations
     - Cast and crew call times
     - Weather forecast for exterior scenes
     - Location maps and contact information
     - Nearest hospital information

2. **Customization**
   - Add special notes or instructions
   - Adjust call times as needed
   - Include additional crew or equipment notes
   - Add safety reminders or protocols

3. **Distribution**
   - Email automatically sent to all cast and crew
   - SMS reminders sent for early call times
   - PDF available for download and printing
   - Mobile app notifications for schedule changes

### 6. Asset and Post-Production Management

#### Digital Asset Organization

1. **Asset Upload and Tagging**
   - Upload raw footage and production stills
   - Add metadata (scene, take, camera angle)
   - Tag assets with relevant keywords
   - Organize by shooting day or scene

2. **Collaborative Tagging System**
   - Editors tag clips with post-production needs:
     - `#VFX-Needed` - Requires visual effects work
     - `#Foley` - Needs sound effects added
     - `#ADR` - Requires additional dialogue recording
     - `#Color-Correction` - Needs color grading
     - `#Music` - Requires music or score

3. **Version Control**
   - Track different versions of edited sequences
   - Maintain approval workflows for cuts
   - Archive previous versions for reference
   - Manage final delivery versions

#### Reshoot Workflow

1. **Flagging for Reshoots**
   - Editors or directors flag clips needing reshoots
   - Specify reason and requirements
   - Add detailed notes about what's needed
   - Assign priority level (critical, important, nice-to-have)

2. **Reshoot Planning**
   - Reshoot requests automatically create tasks in stripboard
   - Schedule reshoot days with available cast and crew
   - Coordinate location availability
   - Track reshoot budget impact

3. **Reshoot Execution**
   - Use same production monitoring tools
   - Track completion of reshoot requirements
   - Update asset management with new footage
   - Close reshoot requests when complete

## 🆘 Troubleshooting and Support

### Common Issues and Solutions

#### Login and Access Issues

**Problem**: Can't log in to account
**Solutions**:
1. Check email and password spelling
2. Use "Forgot Password" to reset
3. Clear browser cache and cookies
4. Try incognito/private browsing mode
5. Contact admin if organization access issues

**Problem**: Don't have access to specific project
**Solutions**:
1. Check with project producer or admin
2. Verify your role assignments
3. Ensure you're in the correct organization
4. Request access through the platform

#### Mobile App Issues

**Problem**: App won't sync data
**Solutions**:
1. Check internet connection
2. Force close and restart app
3. Log out and log back in
4. Update to latest app version
5. Clear app cache (Android) or reinstall (iOS)

**Problem**: GPS location not working
**Solutions**:
1. Enable location permissions in device settings
2. Ensure GPS is enabled
3. Try restarting location services
4. Check for app updates
5. Restart device if necessary

#### Performance Issues

**Problem**: Slow loading or timeouts
**Solutions**:
1. Check internet connection speed
2. Clear browser cache
3. Close unnecessary browser tabs
4. Try different browser
5. Contact support if issues persist
